# weekday-hour-direction-heatmap-indicator-pine

TradingView Pine v6 indicator: average return / bullish ratio heatmap by weekday and hour

曜日×時間帯ごとに、**値動きの方向の偏り**（平均リターン、または陽線で終わった割合）を表にして表示するインジケーターです。「どの時間帯に、上下どちらへ動きやすいか」の**候補探し**に使います。

値幅（動きの大きさ）を調べるインジケーターは [weekday-hour-volatility-heatmap-indicator-pine](https://github.com/stangler/weekday-hour-volatility-heatmap-indicator-pine) です。

- ファイル名（推奨）: `weekday-hour-direction-heatmap-indicator.pine`
- スクリプト名: `曜日×時間帯 方向性ヒートマップ`
- 時刻: 日本時間（入力でタイムゾーンを変更できます）

## 表示内容

- 縦軸は時間（0〜23時）、横軸は曜日（月〜日）です。
- 各マスは、その曜日・時間帯の1時間について、**始値から終値までの変化**の平均です。
- 色は、**赤が上昇方向、青が下落方向**です（陽線が赤のチャート設定に合わせています）。濃いほど偏りが強くなります。
- 標本が3回未満のマスは「-」で表示されます。

### 表示の切り替え

| 表示 | 内容 |
|---|---|
| 平均リターン(pips) | 1時間の始値→終値の平均（pips） |
| 陽線の割合(%) | 陽線で終わった割合（50% が中立） |

### 「＊」の意味

「＊」は、偏りが統計的にある程度はっきりしている目印です（`|t| ≥ 2` 相当）。

- 平均リターンの表示: 平均が 0 から離れているかの t 値
- 陽線の割合の表示: 50% から離れているかの二項分布の近似

## 使い方

1. TradingView の Pine エディタで、**新規のインジケーター**を作成します。
2. `weekday-hour-direction-heatmap-indicator.pine` の内容を貼り付けて、保存します。
3. **1時間足以下**のチャートに追加します（1時間足を推奨）。
4. 右中央に表が表示されます。

1時間足は、過去のデータを長く読み込めるため、各マスの標本が増えます。15分足は、過去のデータが短く、標本が少なくなります。

## 見るときの注意（重要）

- **偶然で偏りが出ます。** 168 マス（7曜日×24時間）のうち、偶然でも約 5% は「＊」が付きます。1マスだけの偏りは、信用しません。
- 見るのは、**隣り合う時間帯や複数の曜日で、同じ方向の偏りが続いている場所**です。
- 見つけた候補は、**必ず別の期間のデータ（期間外）で検証**してから使います。
- 経済指標やFOMCなど、特定のイベント日の影響で平均が偏ることがあります。年に数回の出来事に頼った偏りは、戦略には向きません。
- 同じデータで選んで同じデータで検証すると、結果は良く出ます。表から見つけた候補を、同じデータでバックテストしても、独立した確認にはなりません。

### 検証の実績（ドル円）

このヒートマップで見つけた3つの候補を、期間外（2025-01-01〜2026-05-31、1時間足）で検証した結果です。

| 候補（火〜金、1時間保有） | PF | 取引回数 | 結果 |
|---|---|---|---|
| **5時売り** | **1.561** | 293 | 残った |
| 0時買い | 1.144 | 291 | 弱いため見送り |
| 4時買い | 1.112 | 294 | 優位性なしで見送り |

3つのうち、期間外でも残ったのは5時売りだけでした。残った5時売りは、[ストラテジー](https://github.com/stangler/usdjpy-tokyo-range-breakout-strategy-pine)に組み込まれています。

## pips の定義

pips は、`(終値 − 始値) / (最小価格単位 × 10)` で計算します。円ペア（小数3桁）では 1 pip = 0.01 円です。金など別の銘柄では、1 pip の大きさが変わります。

## 入力パラメータ

| 項目 | 既定値 |
|---|---|
| タイムゾーン | Asia/Tokyo |
| 表示 | 平均リターン(pips) |

## 表の曜日の見方

曜日は、**1時間の開始時刻の曜日**（日本時間）で数えます。たとえば、土曜の早朝（0〜6時）は、実際には金曜のNY市場の時間帯です。日曜の列は、通常は空欄になります。
